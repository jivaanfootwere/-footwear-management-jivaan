Initial setup

Connect this dashboard to your Supabase project by adding the project URL and publishable/anon key in the CONFIG section of this file. Never put a service-role key or Meta access token here.

Database tables and access rules are supplied in schema.sql. Run that SQL in Supabase SQL Editor, then create your first user in Authentication and promote that user to admin using the SQL instruction in README.

WhatsApp API tokens stay only in Supabase Edge Function secrets. Sending needs the approved JIVAAN token template and a verified Meta setup.
