# JIVAAN automatic WhatsApp token delivery

The function `send-footwear-token` sends the PNG token generated by the staff dashboard.

## Required Supabase Edge Function secrets

Set these in Supabase Dashboard → Edge Functions → Secrets:

- `META_WHATSAPP_TOKEN`: Meta WhatsApp Cloud API access token
- `META_PHONE_NUMBER_ID`: WhatsApp Cloud API phone number ID
- `META_GRAPH_API_VERSION`: supported Graph API version, for example `v23.0`
- `META_TEMPLATE_NAME`: approved WhatsApp template name; defaults to `jivaan_footwear_token`
- `META_TEMPLATE_LANGUAGE`: approved template language code; defaults to `en`

Never put these values in the website, GitHub source, or chat.

## WhatsApp template required

Create and get approval for a Utility template with:

- Header: Image
- Body text with exactly three text placeholders:
  1. Bag number
  2. Token ID
  3. Expiry date/time

Suggested body:

Your JIVAAN footwear deposit is confirmed.
Bag number: {{1}}
Token ID: {{2}}
Valid until: {{3}}
Please show the attached token image when collecting your footwear.

The template name and language must match the Supabase secrets exactly. Meta must approve the template before sending can work.

## Deployment

Deploy this function to the Supabase project `navamrnvmcxudctthcbe` using the Supabase Dashboard Edge Functions editor or the Supabase CLI. The function uses the logged-in staff JWT, checks the staff profile role and saved deposit, then uploads and sends the token image through WhatsApp Cloud API.

A successful API response means WhatsApp accepted the message request. Delivery status should be confirmed from WhatsApp message status/webhook events; acceptance is not the same as delivery.
